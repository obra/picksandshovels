# PICKS & SHOVELS

A 3D pixel-art browser game about the AI industry, for picksandshovels.org.

Sell the GPUs. Ride the hype. Keep p(doom) under 100%.

## Develop

    npm install
    npm run dev        # local dev server
    npm test           # sim + content unit tests
    npm run simulate   # headless balance runs (see scripts/simulate.mjs --help)
    npm run build      # static site in dist/
